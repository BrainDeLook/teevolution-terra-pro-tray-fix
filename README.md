# Teevolution Terra Pro — исправление работы в трее

Неофициальный локальный патчер для приложения **Teevolution Terra Pro 1.0.0.43** (.NET Framework 4.8).

- Запуск с `-startup` действительно скрывает окно: оно не остаётся в Alt+Tab.
- Крестик окна и Alt+F4 скрывают приложение в трей.
- Левый клик по значку или пункт открытия в меню трея возвращает окно.
- Полный выход — правый клик по значку → «Выйти».
- Встроенная настройка автозапуска передаёт `-startup`.
- Завершение сеанса Windows не блокируется.

Изменения применяются к окну выбора устройства и окну настройки мыши. Языковые файлы, конфигурация, макросы и прошивки не изменяются.

## Установка

1. Скачайте ZIP из [последнего релиза](https://github.com/BrainDeLook/teevolution-terra-pro-tray-fix/releases/latest) и распакуйте его полностью.
2. Завершите Teevolution через меню значка в трее.
3. Запустите `Apply.cmd`. Для установки в Program Files Windows запросит права администратора.
4. Запустите Teevolution обычным способом. Крестик теперь скрывает окно.

Для скрытого запуска используйте ярлык с объектом:

```text
"C:\Program Files (x86)\Teevolution Terra Pro\Mouse Drive Beta.exe" -startup
```

Если автозагрузка уже была включена в старой версии, отключите и снова включите её в настройках исправленного Teevolution. Патчер сам не включает автозагрузку и не запускает приложение.

Для нестандартной папки установки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Patch.ps1 -InstallDirectory "D:\Apps\Teevolution Terra Pro"
```

## Откат

Завершите приложение через трей и запустите `Restore.cmd`. Оригинальный EXE хранится рядом с приложением как `Mouse Drive Beta.exe.teevolution-original.bak`. При повторном применении этот файл не перезаписывается. Несовпадение контрольных сумм останавливает операцию.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Patch.ps1 -Mode Status
```

## Совместимость и проверка

Поддерживается только EXE с SHA256:

```text
48E7DB906FA30B99A828FEBE502F6BF0BE16BE3852D67CB78A6C0F43BF759BFD
```

После применения SHA256:

```text
7BF423BFFC74DD260560B7E3F0B8D51A6ED7C089C21D90A3FB5A57A0B6DA35D3
```

Перед заменой проверяется результат патчера. Замена EXE и создание резервной копии выполняются атомарно. Для другой версии приложения патчер откажется от изменений. Патчер не устанавливает драйверы, не изменяет прошивку мыши и не меняет настройки безопасности Windows.

## Сборка

На Windows с .NET SDK 10:

```powershell
.\Build.ps1
```

Для запуска готового патчера достаточно .NET Framework 4.8, который требуется самому Teevolution. Используется Mono.Cecil 0.11.6; его лицензия включена в пакет. Оригинальный и изменённый EXE производителя в репозитории и релизе не распространяются.

`tests/TrayTest.cs` — локальная проверка на пользовательской копии приложения. Она проверяет скрытый старт, реальные обработчики крестика, восстановление окна, обычное закрытие и разрешённое завершение Windows; отдельные режимы проверяют штатный выход из трея. Проверка взаимодействия с физической мышью и прошивкой в этот тест не входит.

Все эти проверки выполнены локально на поддерживаемом EXE. Дополнительно `tests/InstallerTest.ps1` проверил применение, резервную копию, повторный запуск, откат, повторное применение и отказ при неподходящем EXE или повреждённой резервной копии. GitHub Actions проверяет синтаксис скриптов и сборку; файлы приложения производителя для runtime-тестов в CI не загружаются.
